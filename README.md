# Star Wars: Empire Rebuilt (2018)

A Star Wars themed incremental game in the style of Cookie Clicker, built in Unity in 2018. Earn credits, buy upgrades, and grow your output.

A rebuilt version lives in [EmpireRebuilt_Remake](https://github.com/arogan178/EmpireRebuilt_Remake).

## Running it

1. Install Unity **2022.3.19f1** (or another 2022.3 LTS) through Unity Hub.
2. Clone the repo and add the folder as a project in Unity Hub.
3. Open `Assets/Scenes/Main Menu.unity` and press Play.

## Project layout

- `Assets/Scripts/Main Menu Scripts` — menu logic
- `Assets/Scripts/Game Screen Scripts` — gameplay, shop and score logic
- `Assets/Scenes` — `Main Menu` and `Main Scene`
